# 比赛独立赛场与图标精简

## 改动

- 比赛列表入口继续打开新标签页；赛场内无列表侧栏。
- 报名、比赛题目、排名、提交记录分别使用 register / problems / standings / submissions 子路由，刷新、后退保留当前页面。
- 报名和题目页不请求榜单/提交记录；榜单和记录仅各自刷新，离页取消请求和定时器。
- 保留校赛身份、预备题选择/排序、不封榜、虚拟赛及服务端源码查看权限；边界时间更新比赛状态。
- 清理首页、个人中心、排行榜、导入页、题目页中的 Sparkles、装饰 emoji 和大型插画；保留搜索、通知、编辑等功能图标。
