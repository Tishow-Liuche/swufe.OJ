# 比赛管理员补录参赛者：验收记录

## 使用入口与规则

管理员进入比赛的“报名”页，下方为“补录参赛者”。支持单人账号/绑定学号、Excel/CSV 预览后批量导入；可下载空白模板。每批最多 500 人，文件最多 5 MB。

所有 ACM/IOI、公开/私有/密码/校赛及团队模式均使用同一后端接口。普通用户和教师不能调用管理员补录接口。允许绕过报名截止时间和比赛密码，不允许在比赛结束后补录。校赛要求已绑定学号和真实姓名。重复导入不覆盖原报名、虚拟时间或成绩。不创建账号，不按昵称模糊匹配。

## 可重复执行

后端：`npm test -- --runInBand`、`npm run build`。

前端：`npm test -- --run`、`npm run build`。

数据库集成：在已配置 `DATABASE_URL` 的后端环境运行 `ALLOW_ISOLATED_IMPORT_TEST=1 node scripts/test-participant-import-db.cjs`。仅创建随机命名空测试 schema，不复制业务数据；需要临时建 schema 权限，结束后自动清理。
