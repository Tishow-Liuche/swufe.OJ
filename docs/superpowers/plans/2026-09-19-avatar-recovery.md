# Avatar Recovery Plan

目标：修复上传过头像的用户因图片请求失败而永久显示姓名缩写的问题。服务器只读核实目标头像存在，新签名HTTPS URL返回200、JPEG 77785字节；原组件 error 后只设置 imageFailed，没有重试；签名有效期300秒。不能据此断言截图唯一原因就是过期。

方案：保留私有对象存储与签名机制，前端组件报告失败URL，auth store仅针对当前用户当前头像限次重新获取profile中的avatar；等待1.1秒跨越签名时间精度，合并并发恢复，30秒冷却，不修改其它资料，不因图片服务错误清除登录。顶部与个人中心读取同一头像和恢复版本。登出或换账号期间旧请求不可回写。

不修改后端权限、不公开存储桶、不改真实账号头像、不变更认证策略。
