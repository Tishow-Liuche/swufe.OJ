# 独立比赛赛场

用户要求：比赛新标签页进入后不显示左侧栏目；报名、题目、排名、提交记录分页面；移除明显装饰性、模板化图标。沿用用户此前直接执行、不反复确认的偏好。

## 方案

选择独立赛场布局和四个子路由，而不是同页锚点或仅 CSS 隐藏。比赛列表和创建表单保留；列表点选继续新标签页打开。赛场只有返回比赛列表、标题、状态、起止时间和文字页签。

- `/contests/:id` 跳转 `/contests/:id/register`。
- `/register`：比赛说明、赛制、报名时段、身份要求、报名/虚拟参赛操作。
- `/problems`：比赛题目列表，保留服务器给出的次序和赛前/报名权限限制。
- `/standings`：ICPC 风格成绩表；保留 AC/WA/待评测/首次通过语义以及赛后源码查看。
- `/submissions`：独立提交记录表，保留时间、语言、结果、耗时、内存和授权源码查看。

刷新、前进后退和直接链接均保留当前页。只在排名页/记录页轮询对应接口；离页后停止定时器，隐藏标签页降低频率。竞赛详情加载有错误态，403 不伪装成无数据；不会修改后端权限或放宽赛前题目访问。报名成功重新拉取详情。

## 视觉

白底、细边框、克制的蓝灰强调色，文字导航下划线表示当前页。无渐变大图标、装饰圆环、闪光/火箭/奖牌 emoji。功能按钮保留文字和必要的搜索/关闭/返回线条图标。首页、个人中心、排行榜和共享题目状态徽标一并去除同类装饰，功能不变。

## 验收

浏览器验证四页相互独立、无赛场侧栏、深链接刷新和历史导航正常；切页后旧轮询停止；报名和私有榜单权限错误清晰；排名绿色/红色/首通过标记保留；源码详情可打开。桌面/手机无页面横向溢出，表格自身可滚动。前后端测试及构建后推送 42411036，保留判题隧道部署，只重建前端。
