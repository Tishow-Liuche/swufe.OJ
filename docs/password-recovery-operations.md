# 短信找回密码运维说明

目前未开通短信服务。网站展示找回入口但禁用发送/重置按钮，并提示联系管理员；接口返回 503，不产生虚假的发送成功记录。

接入腾讯云短信时，只在服务器 `config/app.prod.env` 配置，勿提交真实密钥：

```
SMS_TENCENT_SECRET_ID=
SMS_TENCENT_SECRET_KEY=
SMS_TENCENT_APP_ID=
SMS_TENCENT_SIGN_NAME=
SMS_TENCENT_TEMPLATE_ID=
SMS_TENCENT_REGION=ap-guangzhou
```

签名和模板必须审核通过。模板接收一个参数：六位验证码，文案有效期为五分钟。使用仅有发短信权限的专用凭据，配置服务商费用告警与日限额。重新创建 backend 容器后才会读取新环境变量。

上线短信前，必须核实历史手机号归属并清理重复号码（不得自动将其中一个账号认定为号码所有者）。当前资料页手机号历史上未经短信确认；服务拒绝对重复号码重置，新保存的号码也会检查已绑定账号。对高风险业务应进一步增加绑定/换绑时的短信验证，再正式启用自助找回。

验证码使用 Redis 保存 HMAC 摘要，五分钟过期；同一号码一分钟一次、一天五次，五次验证错误失效，成功后一次性消费。账号、手机号或 authVersion 改变后旧码不可用。重置成功会撤销已有会话；停用账号不可重置。真实短信送达只能在服务开通后验证，目前未声称验证真实送达。
