SWUFE OJ 脚本安装

安装一次整合脚本，即可在 Codeforces、洛谷和 QOJ 自动填写代码、提交并回传结果。

一键安装三平台整合脚本 返回 OJ
只打开一个安装确认页。请在 Tampermonkey 中点击“安装 / 更新”，然后刷新 OJ 页面。
旧用户注意：整合脚本与三个独立脚本二选一。改用整合脚本前，请在 Tampermonkey 中停用原有三个独立脚本，避免重复交题。也可以只更新下方独立脚本，不安装整合版。
Edge / Chrome：先安装 Tampermonkey。在浏览器“扩展 → Tampermonkey → 详情”中启用“允许用户脚本”（部分版本需要开发者模式），并允许它在本 OJ 和对应外站运行。网页不能代替你开启浏览器扩展权限。
